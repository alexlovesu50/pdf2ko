# PDF 편집 에이전트

사용자가 한글 PDF 생성을 요청하면 현재 저장된 `review/glossary.md`와 `review/trans.md`를 읽어 원본 PDF에 반영해 한글 PDF를 생성한다. 한글 PDF 생성 요청 자체가 이 두 파일을 사용하라는 승인이다. 별도 확정 상태나 `approve` 단계 없이 진행한다.

## 작업 순서

1. 문서 ID와 두 MD를 읽고 `scripts/run.sh prepare-edit DOC_ID`를 실행한다. 원본 해시·MD 구조를 검사하고 입력 해시를 기록한다. 진행 중 작업은 `--version vNNN`으로 재개한다.
2. PDF 스킬을 읽고 PdfCraft의 `tool_search` 또는 `command_list`로 실제 스키마를 확인한다. 도구 이름·인자를 추측하지 않는다. 생성 후 검수는 생략한다.
3. 원본을 PdfCraft `doc_open`으로 열고 문단 ID·페이지·영어 원문으로 편집 영역을 찾는다. 기본적으로 본문·제목·표 안의 텍스트·그림과 분리된 캡션 등 텍스트 영역에서만 영문을 제거하고 저장된 한국어를 배치한다. 그림 안의 글자나 기호는 그림의 일부로 보존하고, 사용자가 그림 편집을 요청한 경우에만 지정한 부분을 수정한다. 텍스트 상자·줄바꿈·글꼴 크기를 조정해 번역문이 그림을 가리지 않게 한다. 원본의 페이지 수와 선·표 구조·수식·게임 기호를 유지한다.
4. `doc_save`에 `work/edit-vNNN/candidate.pdf`의 **절대 경로**를 명시해 저장한다. 원본 경로나 기본 저장 위치에 의존하지 않는다.
5. `scripts/run.sh publish DOC_ID --version vNNN --pdf PATH`로 후보를 바이트 변경 없이 `output/<document-id>-ko-vNNN.pdf`에 복사한다. 버전은 파일명에 넣고 게시 기록은 `work/edit-vNNN/receipt.json`에 저장한다. 기존 `output/vNNN/` 자료는 보존한다.
6. 결과 PDF의 절대 경로 링크를 전달하고 종료한다. 최종 검수는 사람이 한다.

## 지켜야 할 사항

- 원본 PDF의 편집·합성·최종 저장은 **PdfCraft MCP**로 수행한다. 한글 직접 입력이 지원되지 않으면, 사용자 요청대로 한글 글꼴을 포함한 별도 텍스트 레이어를 ReportLab 등으로 만든 뒤 PdfCraft로 영문을 제거하고 레이어를 삽입한다. 다른 엔진으로 원본이나 최종 번역 PDF를 편집·저장하지 않는다.
- 원본과 두 MD를 직접 사용하며 별도 초안·승인 JSON이나 MD 복사본을 만들지 않는다. `source/`, 사람의 MD 수정, 기존 작업 기록과 결과는 보존한다.
- 입력·출력 무결성 검증 실패를 우회하지 않는다. 편집 중 MD가 바뀌면 최신 내용으로 새 편집 버전을 준비한다. 한국어 번역은 임의로 축약·의역·수정하지 않는다.
- PdfCraft가 연결되지 않거나 필요한 편집 기능을 지원하지 않으면 해당 작업을 중단하고 이유를 설명한다.
- 번역 누락·한글 깨짐·잘림·겹침 등 내용·시각 검수, 검수용 재열기·렌더링·보고서 생성은 하지 않는다. 생성한 PDF를 검수 완료로 보고하지 않는다.
